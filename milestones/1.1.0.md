# JEBG Website Milestone 1.1.0
Released 5 November 2026. Google Apps Script version 2 is deployed at the existing endpoint.

## Outcome
The apparent missing records were caused by viewing the separate blank “JEBG MAIN” spreadsheet. The configured website database already contained the developer submission. The destination and all existing records are preserved.

## Included
- Branded, responsive success and error receipts, with reference, submission type, recorded time in India, and received/saved/team-review steps.
- Duplicate receipts explicitly explain that the existing record is retained.
- New saves read back reference, request ID and dedupe hash after flush before returning success.
- Existing validation, consent, rate controls and standard POST with JSON payload are preserved.
- Website snapshot, confirmation previews, original backend backup, and repeatable backend tests.

Some HTTP test attempts lost their response connection; successful retries and direct Sheet readback established the final outcome.

## Deployment and rollback
The backend is already live. GitHub Pages docs/index.html, its image, CNAME and product dropdown are unchanged by this backend release.
Only Code.gs and appsscript.json belong in the Apps Script project. Keep previews, backups and tests outside the project upload.
For future releases, back up the current script, push the two backend files, create a new version, and update the existing deployment. Do not create a new endpoint.
Rollback: point the existing deployment back to Apps Script version 1. This changes code only, not stored rows.
Never publish the private Sheet or put admin links in docs/index.html.
